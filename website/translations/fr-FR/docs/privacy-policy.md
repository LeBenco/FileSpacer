# Politique de confidentialité

Aucune télémétrie, aucun suivi d’usage ni publicité. Les vérifications de mises à jour contactent GitHub ; les vérifications hebdomadaires sont facultatives et désactivées par défaut. Téléchargement et installation demandent confirmation.
