Το FileSpacer είναι ένας διαχειριστής αρχείων για τα Windows που βασίζεται στο [χωρικό μοντέλο](https://en.wikipedia.org/wiki/Spatial_file_manager): κάθε φάκελος έχει ένα μοναδικό παράθυρο που θυμάται τη θέση, το μέγεθος και τις ρυθμίσεις προβολής του. Έτσι δημιουργούνται [σταθερά οπτικά σημεία αναφοράς](https://www.csse.canterbury.ac.nz/~andy/papers/transforms.pdf), ώστε η [χωρική μνήμη](https://www.microsoft.com/en-us/research/wp-content/uploads/1998/01/p153-robertson.pdf) να σας βοηθά να αναγνωρίζετε γνώριμους φακέλους με μια ματιά. Σε έναν διαχειριστή αρχείων που βασίζεται στην πλοήγηση, το ίδιο παράθυρο εμφανίζει διαδοχικά διαφορετικούς φακέλους: η θέση και οι διαστάσεις του δεν αρκούν για να προσδιορίσετε τον ανοιχτό φάκελο, οπότε πρέπει να κοιτάξετε το περιεχόμενό του για να προσανατολιστείτε. Διατηρώντας ξεχωριστά σημεία αναφοράς για κάθε φάκελο, η χωρική προσέγγιση μπορεί να μειώσει τη νοητική προσπάθεια που χρειάζεται για να βρείτε τον δρόμο σας ανάμεσα στα αρχεία σας. Οι καρτέλες δεν είναι συμβατές με το χωρικό μοντέλο και δεν θα προστεθούν ποτέ.

<img src="images/spatial-windows-el.png" alt="Τρία παράθυρα φακέλων χωρίς επικάλυψη, με διαφορετικό μέγεθος, προβολή και μεγέθυνση, με ένα σε ελεύθερη διάταξη εικονιδίων." width="560">

Το FileSpacer δίνει προτεραιότητα σε μια ελαφριά και απλή εμπειρία χρήσης. Για να περιορίσει τη συσσώρευση παραθύρων, ένα γνωστό μειονέκτημα του χωρικού μοντέλου, το FileSpacer κλείνει από προεπιλογή το παράθυρο προέλευσης όταν ανοίγετε έναν φάκελο. Κρατήστε πατημένο το Ctrl κατά το άνοιγμα για να το διατηρήσετε ανοιχτό όταν θέλετε να εργαστείτε με πολλούς φακέλους ταυτόχρονα. Το FileSpacer διατηρεί μια σκόπιμα λιτή διεπαφή, σε αντίθεση με ορισμένα παραφορτωμένα περιβάλλοντα που αφήνουν ίσα ίσα χώρο ανάμεσα στα κουμπιά για να διακρίνετε ένα αρχείο.

<a id="system--languages"></a>**Σύστημα και γλώσσες:** Windows 10 ή νεότερη έκδοση, x64. Διατίθεται σε δέκα γλώσσες: αγγλικά, γαλλικά, γερμανικά, ιταλικά, ισπανικά, πορτογαλικά (Πορτογαλία), ελληνικά, πολωνικά, ολλανδικά και ουκρανικά.

Οι εβδομαδιαίοι είναι προαιρετικοί και απενεργοποιημένοι από προεπιλογή. Η λήψη και η εγκατάσταση απαιτούν επιβεβαίωση. **Εγκατάσταση:**

- **Χειροκίνητη εγκατάσταση:** λήψη και εκτέλεση του <a href="https://github.com/LeBenco/FileSpacer/releases/download/v1.3.2/FileSpacer-1.3.2-install.exe" id="last-release-url">προγράμματος εγκατάστασης της τελευταίας έκδοσης</a>.
- **WinGet:** `winget install --id Benco.FileSpacer --exact`
- **Chocolatey** (τερματικό με δικαιώματα διαχειριστή): `choco install filespacer -y`

Τα πακέτα WinGet και Chocolatey αναμένουν έγκριση στους αντίστοιχους καταλόγους.

## Δυνατότητες

- **[Ένα παράθυρο για κάθε φάκελο](user-guide.md#πλοήγηση-μεταξύ-παραθύρων)**. Η θέση, το μέγεθος, η λειτουργία προβολής και οι θέσεις των εικονιδίων αποθηκεύονται. Τα εικονίδια μπορούν να τοποθετηθούν ελεύθερα ή να ευθυγραμμιστούν στο [κλασικό πλέγμα](user-guide.md#διάταξη-εικονιδίων).
- **Αυτόματη διάταξη παραθύρων**. Το άνοιγμα ενός άλλου φακέλου κλείνει από προεπιλογή το παράθυρο προέλευσης. Τα παράθυρα χωρίς αποθηκευμένη θέση τοποθετούνται έτσι ώστε να [περιορίζεται η επικάλυψη](user-guide.md#τοποθέτηση-παραθύρων).
- **Διαχείριση παραθύρων**. Μετακίνηση ή αλλαγή μεγέθους παραθύρων με [χειρονομίες του ποντικιού](user-guide.md#μετακίνηση-και-αλλαγή-μεγέθους). Αποθήκευση και επαναφορά [ομάδων φακέλων](user-guide.md#ομάδες-φακέλων). [Κλείδωμα της διάταξης των παραθύρων](user-guide.md#κλείδωμα-αποθηκευμένης-διάταξης).

## Ενσωμάτωση

Το FileSpacer μπορεί να οριστεί ως προεπιλεγμένος διαχειριστής αρχείων κατά την εγκατάσταση ή αργότερα από τις ρυθμίσεις. Τα αρχεία ανοίγουν με τη συνηθισμένη εφαρμογή των Windows. Οι φάκελοι δικτύου ακολουθούν τη λειτουργία των Windows. [Ενσωμάτωση στα Windows](user-guide.md#ενσωμάτωση-στα-windows).

Με το **Everything** μπορούν να ξεκινήσουν σύνθετες αναζητήσεις από το πεδίο του FileSpacer, στον τρέχοντα φάκελο και τους υποφακέλους του ή σε όλα τα αρχεία του ευρετηρίου. Τα αποτελέσματα ανοίγουν στο Everything. [Ενσωμάτωση και χρήση](user-guide.md#everything).

Με το **Nilesoft Shell**, τα μενού του FileSpacer μπορούν να χρησιμοποιούν τα θέματά του και προσαρμοσμένες εντολές. Συνιστάται προσαρμογή της διαμόρφωσης για ομοιόμορφη εμφάνιση. [Ενσωμάτωση και διαμόρφωση](user-guide.md#nilesoft-shell).

## Μεταγλώττιση

[![Publish FileSpacer](https://github.com/LeBenco/FileSpacer/actions/workflows/release.yml/badge.svg)](https://github.com/LeBenco/FileSpacer/actions/workflows/release.yml)

Η μεταγλώττιση χρησιμοποιεί MSVC/NMAKE, Visual Studio 2022 Build Tools με ATL και ένα Windows SDK, Inkscape και ImageMagick. Για το πρόγραμμα εγκατάστασης απαιτείται το NSIS. Το SQLite περιλαμβάνεται. Δείτε τον [οδηγό μεταγλώττισης](../en/build.md).

Οι δοκιμές παλινδρόμησης συνδυάζουν σενάρια PowerShell με βοηθητικά εργαλεία C++ και C# για εσωτερικούς ελέγχους και πραγματικές δοκιμές του περιβάλλοντος των Windows και του Shell. Η [ροή εργασίας παλινδρόμησης του GitHub Actions](https://github.com/LeBenco/FileSpacer/actions/workflows/regression.yml) εκτελεί αυτή τη σουίτα της εφαρμογής κατόπιν αιτήματος και αυτόματα πριν από μια δημοσίευση. Οι ίδιες περιπτώσεις εκτελούνται με το `tests.cmd` σε τοπική επιφάνεια εργασίας Windows ή σε ρυθμισμένη εικονική μηχανή Hyper-V. Ο [οδηγός δοκιμών](../en/tests/regression/README.md) εξηγεί την επιλογή περιπτώσεων, τις προϋποθέσεις και τα αποτελέσματα.
