# Privacy policy

No telemetry, usage tracking or advertising. Update checks contact GitHub. Weekly checks are optional and off by default. Downloading and installing require confirmation. To speed up the handling of large folders, FileSpacer downloads symbol files from Microsoft; this download is optional and on by default.

[Details in the user guide](https://github.com/LeBenco/FileSpacer/blob/main/docs/en/user-guide.md#privacy).
