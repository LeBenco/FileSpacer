# Політика конфіденційності

Без телеметрії, відстеження використання чи реклами. Перевірки оновлень звертаються до GitHub. Щотижневі перевірки необов’язкові й за замовчуванням вимкнені. Завантаження й інсталяція потребують підтвердження.
