# Реалізація меню рядка заголовка

Редагування й групи описує [посібник користувача](user-guide.md#customize-the-title-bar-menu). Почніть із `TitleMenu.h`, `TitleMenuDialog.cpp`, `TitleMenuRenderer.cpp` і `FolderGroups.cpp`; робочі команди обробляє вікно папки.

<a id="composition-and-rendering"></a>

## Склад і відображення

Настройки зберігають сталі значення `TitleMenuEntry`, незалежні від перекладених написів і динамічних ID відкритих вікон. `validTitleMenu()` приймає до 64 пунктів, дозволяє повторні роздільники й відхиляє дублікати дій. Пункт відкритих вікон — блок, що розгортається з поточного списку під час відкриття меню, а не команда для постійного вікна.

Редактор зберігає відразу після OK; Скасувати відкидає чернетку. Відновлення стандартних значень змінює лише чернетку. Інші вікна читають склад під час наступного відкриття меню. Зберігайте перевірки контексту й доступності дій під час переміщення або зовнішнього виклику.

FileSpacer формує меню, потім Nilesoft Shell застосовує правила. Додані або розміщені Nilesoft пункти доступні лише для читання. Перейменований пункт можна редагувати, якщо Nilesoft не керує позицією; неоднозначні послідовності роздільників обережно вважаються зовнішніми.

Попередній перегляд використовує справжній засіб відображення Windows/Nilesoft в одноразовому процесі FileSpacer на приватному робочому столі. Показані дії ніколи не викликаються. Під час перетягування зберігайте захоплені пікселі меню. Якщо шарове тло Nilesoft не захоплюється, використовуйте явний непрозорий резервний варіант замість імітації акрилу композитора.

<a id="action-boundaries"></a>

## Межі дій

- Відновлення заблокованого розташування застосовує геометрію/подання через наявне подання без втрати вибору. Заміна еталона захоплює поточне розташування під наявним блокуванням і потребує підтвердження.
- Забування розташування очищує розташування/блокування, залишаючи журнал пошуку. Поточне вікно не зберігає його до закриття, якщо явно не заблокувати заново.
- Закриття вкладених/інших вікон використовує звичайне закриття й збереження, зокрема між процесами. Припасування використовує нативні положення, інтервали й видимі ширини стовпців у межах робочої області монітора.
- Групи зберігають іменовані списки незалежно від меню. Відкриття активує кожну папку з її розташуванням, залишаючи інші вікна. Видалення групи не видаляє папок; скидання загальних настройок не очищує груп.

<a id="nilesoft-command-bridge"></a>

## Міст команд Nilesoft

Наведено сталі ID `WM_COMMAND`. Вони відрізняються від збережених `TitleMenuEntry` і динамічних ID списку вікон. Nilesoft може викликати відсутню в меню дію через [`window.command`](https://nilesoft.org/docs/functions/window). Усередині правила лише для меню заголовка FileSpacer:

```nss
item(title='Припасувати вікно до вмісту' cmd=window.command(1128))
```

Власник меню передає команду справжньому вікну папки; перевірки життєвого циклу, контексту й блокування зберігаються. Область і вигляд: [довідник конфігурації](nilesoft-shell.md).

| --- | ---: |
| Копіювати шлях | 1120 |
| Перейменувати | 1008 |
| Заблокувати стан вікна | 1100 |
| Властивості | 1121 |
| Закрити батьківські вікна | 1122 |
| Знову відкрити останнє закрите вікно | 1021 |
| Настройки FileSpacer | 1009 |
| Відновити заблоковане розташування | 1123 |
| Замінити еталонне розташування | 1124 |
| Забути розташування цієї папки | 1125 |
| Закрити вікна вкладених папок | 1126 |
| Закрити інші вікна | 1127 |
| Припасувати вікно до вмісту | 1128 |
| Зберегти / відкрити групу папок | 1129 |

<a id="tests"></a>

## Тести

Група `33-menu-titre` перевіряє нативний склад і дії в Debug `/test` з ізольованими настройками, групами й станом папок. Цей режим виключає Nilesoft із меню/редактора. Явний тест сумісності може ввімкнути `FILESPACER_TEST_NILESOFT=1` у власному середовищі процесу; Release ігнорує це. Нативні тести не перевіряють відображення Nilesoft.

Тести сумісності використовують наявну інсталяцію Nilesoft та окрему тестову конфігурацію. Збережіть і точно відновіть стан реєстру й конфігурації, зокрема після перевищення часу. Бінарні файли Nilesoft не поширюються з FileSpacer або звичайними тестами. Не копіюйте інстальовані DLL до опублікованих артефактів; зберігайте відповідні ліцензійні повідомлення окремих залежностей.
