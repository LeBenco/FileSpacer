# Журнал змін

## Ще не випущено

- Значно прискорити зменшення великих виділень клацанням елемента або тла у класичних поданнях Shell, з автоматичним і непомітним переходом на загальнодоступний механізм, якщо приватна можливість Windows недоступна.
- Прискорення читання повних і великих часткових виділень у режимах піктограм із вільним розташуванням через загальнодоступні API Windows.
- Увімкнення та вимкнення ескізів у Windows глобально через меню «Вигляд».
- Відновлювати позицію прокручування папки під час повторного відкриття її вікна.
- Розміщувати нові вікна з урахуванням звичайного розміру й положення наявних вікон FileSpacer, зокрема розгорнутих, згорнутих або прикріплених до країв екрана.
- Багаторазове прискорення команди «Вибрати все» та скасування вибору тисяч файлів у класичних поданнях оболонки. Ця оптимізація використовує приватні функції Windows, доступність і поведінка яких не гарантовані. Якщо ці функції відсутні або несумісні, FileSpacer автоматично й без повідомлень повертається до публічних функцій, без виграшу у швидкодії.

## 1.0.0 — 2026-10-09

- Перший випуск FileSpacer для Windows 10 або новішої, x64, на основі ChromaFiler.
- Просторова навігація з одним вікном на папку та постійними положенням, розміром, поданням і піктограмами в SQLite.
- Відстеження переміщень і перейменувань та активація наявного вікна під час повторного відкриття папки.
- Типове закриття вихідного вікна під час відкриття папки чи предка, налаштовуване й обернене через Ctrl.
- Додано навігаційні ланцюжки й редагований рядок шляху та фільтр імен із необов’язковим фільтруванням під час введення.
- Налаштовувані елементи панелі інструментів, нижній рядок стану й групування панелі завдань.
- Додано необов’язкові експериментальні повні імена вибраних елементів.
- Додано англійський і французький інтерфейси з англійським як резервним.
- Додано відновлення після аварій і команди скидання настройок або стану папок.
- Прибрано колонки Міллера, вбудований текстовий редактор, вікна перегляду й плаваючий лоток.
- Додано сценарії MSVC/NMAKE, інсталятор NSIS, автоматичні випуски GitHub й документацію проєкту.
